# UI Skills

Private collection of skills and UI toolkits.

## Imported skills

- [`skills/colorfigures`](skills/colorfigures): the complete eight-file [Colorfigures package](https://april-zhu.com/colorfigures) from its official ZIP (SHA-256 `c5f05302d78db757859f7e9c563f20a5482f3cd07e5a44050486289e7fd80143`), plus a local [provenance manifest](skills/colorfigures/PROVENANCE.json). The description is YAML-quoted for Codex compatibility; its decoded text, instruction body, and all executable files are unchanged. MIT notices for April Zhu and Tolga Cohce are preserved. Its Python builder packages trusted figure code into interactive HTML; it is not an untrusted-HTML sanitizer. Browser QA is a separate validation step.

- [`skills/anatomy`](skills/anatomy): Anatomy, imported unchanged from [wheresryan22/anatomy](https://github.com/wheresryan22/anatomy) at commit [`dbf697a527bbf7d358668e1557cb1e35ff725d46`](https://github.com/wheresryan22/anatomy/commit/dbf697a527bbf7d358668e1557cb1e35ff725d46). The upstream MIT license is preserved at `skills/anatomy/LICENSE`.
- [`skills/isometric-foundry`](skills/isometric-foundry): a new, independent skill for making original interactive isometric figures as offline HTML. Rebuilt from the owner's recorded brief; it is not a recovery of the missing earlier source. Its design was informed by [MrBongoC/ai-iso-skill at `44b4da7714148eef547cc1b102e433472dfe3531`](https://github.com/MrBongoC/ai-iso-skill/tree/44b4da7714148eef547cc1b102e433472dfe3531) (MIT, Copyright 2026 Tolga Cohce; see [third-party notice](skills/isometric-foundry/THIRD_PARTY_NOTICES.md)). [isoglow.dev](https://isoglow.dev/) was a visual/workflow reference only; no code, CSS, examples, assets, or branding were copied.
